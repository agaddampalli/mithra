# Mithra — Personal Life OS

A self-hosted, voice-first agentic orchestration layer that manages all life domains for a household. Mithra reasons across 15 life domains, surfaces what needs attention proactively, and acts through native channels — Google Calendar, WhatsApp, smart speakers — without requiring a new app or dashboard.

## Quick start

```bash
cp .env.example .env
# Fill in all required values in .env
docker-compose up -d
```
