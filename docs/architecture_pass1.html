How data flows: Requests enter through input channels → pass through the Cloudflare edge → reach the agent core for reasoning → agent invokes domain MCP tools (bidirectional) → reads and writes storage (bidirectional) → sends results through output channels. Storage and domains are not sequential — both are accessed directly by the agent core as needed. Pass 2 will zoom into each layer. Pass 3 will trace three real end-to-end scenarios.
